FAQ

Is NIRO Launcher free?

Yes. You still need your own copy of Minecraft: Java Edition to join online servers.

Why does Windows show a warning?

The installer is not code-signed yet, so Windows SmartScreen warns about unknown apps. Click More info, then Run anyway.

Can I join online servers with an offline profile?

No. Offline profiles work for singleplayer and offline-mode servers only. Sign in with a Microsoft account that owns Minecraft: Java Edition to play on online servers.

Do I need Java?

Yes. Recent Minecraft versions need Java 17 or 21. Install Java 21 from adoptium.net. The launcher tells you if Java is missing or too old.

Which systems are supported?

Windows for now.
